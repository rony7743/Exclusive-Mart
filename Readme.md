## ✨ Features

### 👥 User Features
- **Authentication & Authorization** - Secure JWT token-based system
- **Shopping Cart** - Add/remove items with real-time updates
- **Order Management** - Place orders and track status
- **Search Functionality** - Smart product search with filters
- **Real-time Chat System** - Chat with admin support on specific products
- **Responsive Design** - Optimized for all devices
- **User Profile** - Manage personal information and order history
- **Smooth User Experience** - Fast loading and intuitive interface

### 🔧 Admin Features
- **Secure Admin Access** - 16-digit access code protection
- **User Management** - View and manage user accounts
- **Product Management** - Add, edit, and delete products
- **Order Management** - Update order status and tracking
- **Real-time Customer Support** - Chat with customers in real-time
- **Dashboard Analytics** - Sales and user insights
- **Inventory Control** - Stock management system

## 🛠️ Tech Stack

### Frontend
- **React 18** with TypeScript
- **Vite** - Fast build tool and development server
- **TSX** - Type-safe React components
- **Socket.IO Client** - Real-time bidirectional communication
- **CSS3** - Fully responsive design

### Backend
- **Node.js** - Runtime environment
- **Express.js** - Web framework
- **Socket.IO** - Real-time websocket communication
- **JWT** - Authentication tokens
- **RESTful API** - Clean API architecture

### Database
- **MongoDB** - NoSQL database for scalable data storage

### Storage
- **Azure Blob Storage** - Secure image and file storage

### Authentication
- **JWT Tokens** - Secure user session management
